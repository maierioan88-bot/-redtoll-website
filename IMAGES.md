# Site assets layout

GitHub Pages serves from the **repo root**. Keep this structure:

```
index.html
features.html
styles.css
site.js
CNAME
images/
  logo.png
  icon.png
  hero_banner.png
  1.png … 9.png
  features/
    feature-dungeons.png
    feature-village-defense.png
    feature-seven-day-cycle.png
    feature-gathering.png
    feature-crafting.png
    feature-cooking.png
    heart-of-the-game.png
```

Do **not** nest another `website/` folder inside this repo.
Upload new images into `images/` or `images/features/` — never drop them at the repo root.
